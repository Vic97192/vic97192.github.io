Learning Reusable Transition Structures for Query Generation

Motivation

In black-box model extraction, one often begins with a set of available images and queries a teacher to obtain predictions. However, a static query set may cover only a small portion of the teacher's functionality. One possible response is to generate new queries by transforming existing images.

The crucial question is not whether an edit changes an image or even changes a teacher's output. It is whether the edit reveals information that has not already been observed. A transformation can produce large prediction changes while revisiting familiar states, and an edit that works on one starting image may have a different meaning on another.

My current work investigates whether there are local, reusable regularities in the relationship between an image transformation and a teacher's response. If such regularities exist, they may provide a foundation for predicting which queries are likely to reach informative regions without exhaustively trying every edit.

Research questions

  • Can we construct an image-transformation space with actions that are sufficiently consistent to compare and reuse?
  • How should we distinguish response movement from coverage expansion and downstream teaching utility?
  • Do nearby states or similar actions exhibit predictable local response transitions?
  • Can a model learn these relationships from limited prior observations, rather than simply memorize the individual images or endpoints?
  • Does information learned from multiple teachers help adaptation to a previously unseen teacher?

Research trajectory

Phase 1 — Controllable transformations. I first explored deterministic, structured image edits designed to support repeated interventions from a limited set of starting images. The A4 configuration included constrained spectral or Gabor-like interventions, with certain pattern parameters fixed while edit strength varied. These tests helped establish that repeated edits could produce measurable trajectories in teacher-response space.

Phase 2 — Beyond root-specific directions. A limitation of the early design was that trajectories could remain tied to the initial image and offer restricted directional diversity. This motivated A5: an exploration of more flexible, brushstroke-based image generation inspired by neural painting, with the goal of separating the meaning of an action from a particular root image.

Phase 3 — Local transition learning. Building on these generators, I investigated whether a memory-based model could use observed transitions to predict another action's consequences. The intended setting is adaptation to a new teacher after only a small number of queries. Simplified diagnostics have been important here: demonstrating that a model can rank some actions by response movement does not establish that it has learned a reusable state-transition law.

Measurements and evaluation

I examine model responses before and after an edit, typically in the teacher's probability or derived response space. Useful measurements include:

  • Response movement: how much the teacher's prediction changes under an action.
  • Coverage / novelty: whether the new response is far from previously observed response regions.
  • Transition structure: whether the observed action-to-response relationships help predict an unseen transition.
  • Teaching utility: whether the generated queries actually improve the student under a controlled training budget.

These objectives should be evaluated separately. A model may move frequently without visiting novel regions, and increased coverage need not automatically improve student performance.

Current status and open challenges

This is ongoing exploratory work. Initial studies support the feasibility of producing controlled response-space movement, but other experiments expose the difficulty of learning transitions that generalize beyond a fixed image, action inventory, or teacher. I am continuing to study local structure, action semantics, and small-memory adaptation, particularly how to evaluate whether a learned transition mechanism genuinely improves the choice of queries.
